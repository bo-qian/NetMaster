# NetMaster 校园网助手隐私说明

更新日期：2026 年 10 月 2 日

NetMaster 校园网助手帮助用户登录校园网、检测连接并在用户启用后自动重连。本说明适用于当前 Windows 版本。该软件是独立开发的工具，并非学校、Microsoft 或 Cloudflare 的官方应用。

## 处理哪些信息

- **校园网登录信息。** 用户在应用内打开的学校认证网页中自行登录。为了完成用户主动发起的配置，应用会读取该网页向学校认证接口提交的登录请求，并保存重连所需的账号及认证参数。界面只显示脱敏账号。应用在配置测试或自动重连时，使用这些参数向学校认证服务发起请求；用户主动重新认证时，也可能向学校下线接口发送当前账号。
- **本机设置和运行记录。** 应用在本机保存检测间隔、自动重连开关、主题、日志保留天数、网络检测结果及守护事件。日志使用应用生成的事件文字；不会故意写入登录请求体或密码。用户导出或复制日志后，导出的副本由用户自行管理。
- **网络检测和测速流量。** 检测互联网连接时，应用会访问 Microsoft、Xiaomi、Cloudflare 的公共检测地址，并在需要时访问学校登录页。用户点击测速后，应用先检测连接；确认在线才向 Cloudflare 测速服务发送下载和上传测试流量。测速会消耗网络流量，测试请求不包含保存的校园网凭证。这些服务可能按各自规则处理请求中的 IP 地址及网络元数据。
- **内嵌网页数据。** 学校登录页由 WebView2 加载。网页本身可能使用 Cookie、缓存或其他浏览器存储，并与学校服务通信；这部分行为受学校网页的实际实现及其隐私规则影响。

## 保存与保护

NetMaster 不运营接收用户登录信息的云端账号或同步服务。应用配置、日志与 WebView2 数据默认位于当前 Windows 用户的本地应用数据目录 `NetMaster` 下；用户可以在设置中更改配置和日志的保存位置。已保存的登录信息使用 Windows DPAPI 的“当前用户”范围加密，只有该 Windows 用户环境能够正常解密。请同时保护 Windows 账号及电脑访问权限。

当前学校认证服务地址使用 `http://10.10.9.9`，学校登录、下线与自动重连请求按该网页的 HTTP 接口发送。DPAPI 只保护本机保存的副本，**不为这段 HTTP 网络传输提供加密**。请仅在预期的校园网络环境中使用，并以学校公布的登录地址和安全提示为准。

日志默认保留 7 天，用户可在设置中调整为 1–365 天；到期的应用日志在后续写入时清理。更改保存位置时，旧目录会作为恢复副本保留，不会自动删除。WebView2 的 Cookie 和缓存有独立的浏览器数据目录；“清除登录信息”不会保证学校网页的 Cookie、缓存或用户自行导出的日志一并删除。

## 用户控制

用户可以暂停自动重连、关闭 Windows 登录后启动、清除应用保存的登录信息、清除历史日志，或停止后台守护。重新配置会清除原登录信息。用户也可以通过 Windows 应用设置卸载软件；如需清理卸载后仍在自选保存位置的文件、迁移恢复副本或 WebView2 数据，应检查上述本地目录并自行删除。删除前请确认路径属于本应用，避免误删其他文件。
