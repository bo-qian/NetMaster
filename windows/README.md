# NetMaster Windows 版使用说明

NetMaster 帮助你管理上海大学校园网连接。完成一次登录配置后，它可以定期检查网络，并在需要时尝试恢复校园网认证。应用提供连接与守护状态、网络测速和运行日志。v2.0.0 已提交 Microsoft Store 认证，尚未公开上架；正式下载入口将在发布后补充。

## 首次配置

1. 在校园网环境中打开 NetMaster，进入左侧的 **配置** 页面，点击 **开始配置**。
2. 在应用内显示的校园网认证网页上输入账号和密码并完成登录。请等待页面出现学校的认证结果，以及 NetMaster 显示已获取本次登录信息。
3. 如未自动确认有效，点击 **测试本次配置**。测试通过后，点击 **保存并启用守护**。页面显示“配置已完成”、登录信息“已加密保存”，才表示本次配置已保存。
4. 回到 **概览**，分别查看“校园网连接”和“自动守护”的状态。**重新检测**可立即刷新连接结果。

“测试本次配置”只验证本次获取的信息，不会代替保存。配置页上的 **在浏览器中打开** 仅供查看或备用；在外部浏览器登录，NetMaster 无法获取配置所需的信息。

如果开始配置时校园网已经在线，NetMaster 会在继续前提示你：开始或重新认证可能让当前连接暂时断开。请先确认提示，再在应用内完成新的登录。

## 日常使用

**概览**同时显示当前网络连接和后台守护状态。这是两个不同的状态：守护运行中不代表此刻已经连上互联网。配置完成后，可以用 **断网自动重连** 开关暂停或恢复自动恢复功能；**Windows 登录后启动** 决定下次登录 Windows 时是否启动后台，两个开关相互独立。关闭主窗口后，已启用的后台守护仍会继续运行。

点击 **开始测速** 时，NetMaster 会先检查当前互联网连接。无法确认在线时不会继续测速；测速过程中可点击 **取消测速**。结果显示下载、上传的平均／最高／最低速度（MB/s）和延迟（ms）。测速会消耗网络流量，单次测试数据最多约 512 MB，另有协议开销；结果受测试服务器、网络环境等影响，不等于所有下载服务都能达到的速度。

**最近日志**展示概览中的最新记录；点击 **查看全部** 进入 **日志**，可以搜索、按级别或日期筛选、查看记录详情、复制选中记录或导出。**实时更新**控制列表是否继续接收新记录，**自动滚动**控制新记录出现时列表是否跟随移动。

## 更换账号或重新认证

需要更换校园网账号或重新获取登录信息时，进入 **配置**，点击 **重新配置**。确认开始后，旧的已保存登录信息会被清除，自动重连会暂停；如果当前网页已经在线，软件会先尝试退出这次校园网登录。随后按首次配置的步骤重新登录、验证和保存。

配置过程中的 **重新认证** 会丢弃本次尚未保存的信息，并在网页已在线时尝试下线；**取消配置** 会结束本次操作，不会恢复已清除的旧登录信息。请在确认提示中留意这些影响。

## 设置与数据

左下角 **设置** 可调整应用主题、检测间隔、日志保留天数和保存位置。调整后点击 **保存** 才会提交；点击 **取消** 会放弃这些尚未保存的设置。

设置中的三个操作各自需要确认，并在确认后立即生效：

- **清除登录信息**：删除已保存的登录信息并暂停自动重连，也会取消正在进行的配置。
- **清除历史日志**：删除历史记录，保留登录配置和守护开关。
- **停止后台并关闭登录启动**：停止当前后台守护并关闭 Windows 登录后启动，保留已保存的配置和日志。

取消设置窗口不会撤销上述已确认的操作。**关于 NetMaster** 中可以查看版本、项目仓库和问题反馈入口。卸载应用请使用 Windows 的应用设置。

当前 Windows 版独立保存数据，不会自动导入[旧版 Windows 程序](legacy/README.md)的登录信息或日志；从旧版切换时需要重新配置。导出的日志可能包含连接时间和账号相关信息，分享前请自行检查。
