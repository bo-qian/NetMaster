# NetMaster：上海大学校园网自动登录软件

全自动管理 SHU 校园网登录，实现断网自动重连及开机自启，配置完成后即可后台静默运行。

## 版本

| 平台   | 目录       | 说明                        |
|--------|------------|-----------------------------|
| Linux  | `linux/`   | systemd 守护 + TUI 终端面板 |
| Windows| 根目录     | 任务计划 + PySide6 GUI      |

## Linux 版快速开始

```bash
cd linux && ./install.sh
```

然后打开新终端输入 `netmaster`，按 `[6]` 抓取凭证，按 `[1]` 启动守护。

详见 [linux/README.md](linux/README.md)。

## Windows 版快速开始

**核心步骤：抓包 → 生成 → 启动**

### 步骤 1：运行软件
下载 `NetMaster.exe` 至任意文件夹（建议非系统盘），双击运行进入主界面。

### 步骤 2：获取登录凭证
1. 确保电脑已安装 Microsoft Edge 浏览器。
2. 点击主界面顶部的 **【🚀启动抓包】** 按钮。
3. 在弹出的浏览器窗口中登录你的校园网账号。
4. 登录成功后浏览器自动关闭，凭证即被捕获。

### 步骤 3：生成与启动
1. 点击 **【📥生成配置 & 更新任务】** 按钮。
2. 点击 **【▶️立即启动】** 按钮。
3. 当右上角显示绿色 **"状态: 🚀正常守护中"** 时即配置成功。

### 步骤 4：后台静默运行
直接关闭窗口即可，程序已托管至 Windows 系统任务，开机自启后台运行。

### 停止与卸载
重新运行 `NetMaster.exe`，点击红色的 **【🗑️卸载任务】** 即可彻底清理。
