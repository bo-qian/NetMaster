# NetMaster
上海大学校园网自动登录软件

## NetMaster  极简使用教程

本软件旨在全自动管理 SHU 校园网登录，实现断网自动重连及开机自启，配置完成后即可后台静默运行。

---

**核心步骤：抓包 → 生成 → 启动**

#### 步骤 1：运行软件

下载并解压软件包至任意文件夹（建议非系统盘），双击运行 `NetMaster.exe` 进入主界面。

#### 步骤 2：获取登录凭证

1. 确保电脑已安装 Microsoft Edge 浏览器。
2. 点击主界面顶部的黄色大按钮 **【🚀启动抓包 (Edge浏览器)】**。
3. 在自动弹出的 Edge 浏览器窗口中，**正常登录一次**你的校园网账号。
4. 登录成功后，浏览器会自动关闭，凭证即被捕获。

#### 步骤 3：生成与启动服务

1. 回到软件主界面（检测间隔等设置建议保持默认）。
2. **必须**先点击蓝色的 **【📥生成配置 & 更新任务】** 按钮。
3. 接着点击绿色的 **【▶️立即启动 (测试一下)】** 按钮。
4. 观察软件底部状态栏，当显示绿色的 **“状态: 🚀正常守护中”** 字样时，即表示配置成功。

#### 步骤 4：后台静默运行

配置成功后，直接点击右上角关闭软件窗口即可。程序已托管至 Windows 系统任务，会在后台持续监测网络并在开机时自动运行，全程无打扰。

---

**附：停止与卸载**
如需彻底停止服务或删除相关文件，请重新运行 `NetMaster.exe`，点击红色的 **【🛑停止进程 & 卸载】** 按钮，按照提示确认即可清理干净。
